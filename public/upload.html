Help & CSV Format

Your CSV file must include a header row with columns that **exactly match** the database table. The required columns are:

  • Company Name
  • POC Name (Required for validation)
  • Designation
  • Phone Number
  • Email ID (Must be a valid email format)
  • LinkedIn profile (Must be unique)
  • Remarks (Fields with commas must be in quotes, e.g., "Note 1, Note 2")
